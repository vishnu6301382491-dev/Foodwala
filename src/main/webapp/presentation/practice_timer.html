🛡️ High-Yield Panel Q&A Defense Quick-Cards (Sections 6, 7 & 8)

Q1: Why Jaro-Winkler over Levenshtein?

Levenshtein weights all character edits equally. Jaro-Winkler applies prefix scaling ($p=0.1$ up to 4 chars), perfectly matching Indian cuisine misspellings where prefixes are typed correctly ('Dosha', 'Briyani').

Q2: How do you enforce Store Isolation?

Manager JWT sessions bind their verified restaurant_id. Express middleware injects parameterized SQL queries (WHERE restaurant_id = ?), preventing cross-store access.

Q3: How is checkout transaction-safe?

Wrapped in an explicit MySQL InnoDB transaction (START TRANSACTION). Line items, payment records, and status history commit atomically, with automatic ROLLBACK on any error.

Q4: What if WhatsApp webhook drops?

Omnichannel dual-channel architecture. The 25-intent NLP engine is decoupled. If Meta's 24-hr window drops, the system falls back seamlessly to the in-app web widget with zero session loss.
